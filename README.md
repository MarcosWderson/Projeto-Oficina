## 🚗 Sobre o TORU SYSTEM

O TORU SYSTEM é uma plataforma de gestão desenvolvida
para a Toru Auto Center.

Seu objetivo é centralizar o atendimento, os serviços
mecânicos, o estoque de peças e a administração financeira.

## 🛠️ Módulos planejados

- Gestão de clientes e veículos
- Ordens de serviço e orçamentos
- Controle de estoque e autopeças
- Agendamentos
- Gestão financeira
- Integração com WhatsApp
- Relatórios gerenciais
- Gestão de funcionários e permissões
- Integração fiscal futura

## 💻 Tecnologias

- Next.js

- TypeScript
- Tailwind CSS

# Projeto-Oficina
Um amigo me pediu para criar um aplicativo para sua oficina, onde ele consiga catalogar os serviços prestado e consiga ter um estoque e conter o controle do mesmo, consiga dar entrada e saída de produtos, colocar preço, e também consiga fazer a venda, emitir nota fiscal.
