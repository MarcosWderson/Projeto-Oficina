
# TORU SYSTEM — Requisitos do Sistema

## 1. Apresentação

O TORU SYSTEM é uma plataforma web para gerenciamento
das atividades da Toru Auto Center.

## 2. Objetivo

Centralizar os processos administrativos, operacionais
e financeiros de uma oficina mecânica e auto center.

## 3. Perfis de usuário

- Administrador
- Recepcionista
- Mecânico
- Estoquista
- Financeiro

## 4. Requisitos funcionais

RF001 - Cadastrar e gerenciar clientes.
RF002 - Cadastrar veículos vinculados aos clientes.
RF003 - Criar e acompanhar ordens de serviço.
RF004 - Registrar diagnósticos e serviços executados.
RF005 - Elaborar orçamentos e registrar aprovações.
RF006 - Cadastrar produtos, peças e fornecedores.
RF007 - Controlar entradas e saídas do estoque.
RF008 - Registrar vendas de produtos e serviços.
RF009 - Controlar contas a pagar e receber.
RF010 - Gerenciar agendamentos.
RF011 - Gerar relatórios gerenciais.
RF012 - Integrar comunicação via WhatsApp.
RF013 - Controlar permissões por perfil.
RF014 - Manter histórico de alterações.
RF015 - Preparar integração com emissão fiscal.

## 5. Requisitos não funcionais

RNF001 - Interface responsiva.
RNF002 - Autenticação segura.
RNF003 - Comunicação por HTTPS.
RNF004 - Banco de dados PostgreSQL.
RNF005 - Proteção dos dados conforme a LGPD.
RNF006 - Backup e recuperação de dados.
RNF007 - Validação de permissões no servidor.
RNF008 - Registro de operações críticas.

## 6. Tecnologias

Frontend: Next.js, React, TypeScript e Tailwind CSS.
Backend: Next.js com rotas e serviços de servidor.
Banco de dados: PostgreSQL no Supabase.
Versionamento: Git e GitHub.
Desenvolvimento: GitHub Codespaces.

## 7. Estado atual

Fase inicial de desenvolvimento.
Nenhum módulo operacional foi homologado.
